🔄 2. RBAC डेटा फ्लो डायग्राम (DFD)
जब कोई user login करता है या कोई page/API call करता है, तो नीचे दिए गए flow से RBAC decide होता है। Scope हमेशा server side से derive होता है — client orgId trust नहीं किया जाता।

📊 5. Backend RBAC Middleware
Express backend में requireRole middleware API routes पर second layer of defence है। 
function requireRole(...roles) {
  return (req, res, next) => {
    if (!req.user) return next(new ForbiddenError('Authentication required'));
    if (!roles.includes(req.user.role)) {
      return next(new ForbiddenError(`Role '${req.user.role}' does not have access`));
    }
    next();
  };
}

function requireAdmin(req, res, next) {
  requireRole('Super Admin', 'Organization Admin')(req, res, next);
}

function requireAuditor(req, res, next) {
  requireRole('Super Admin','Organization Admin','Audit Manager','Auditor','CA / Consultant')(req, res, next);
}
