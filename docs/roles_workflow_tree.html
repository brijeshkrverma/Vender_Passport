🔒 RBAC सुरक्षा नियम सारांश
1. Frontend Guard: React ProtectedRoute canAccessPage(role, path) चेक करता है। अगर access नहीं, /dashboard पर redirect।
2. Backend Guard: Express requireRole(...) middleware 403 Forbidden देता है।
3. Tenant Isolation: orgId auth session से derived होता है; client-supplied orgId reject किया जाता है।
4. Navigation Filter: AuthContext.jsx में ROLE_ROUTES sidebar visibility control करता है।
5. Demo Mode: MongoDB न होने पर mock user {role, orgId} default Compliance Manager role के साथ चलता है; login dropdown से role simulate होता है।
